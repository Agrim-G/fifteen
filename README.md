# Daily cash closing checklist

A single-page tool for recording end-of-day cash and expenses. Plain HTML, CSS and JavaScript, no build step and no backend.

## Run
Open `index.html` in a browser.

## Deploy
- GitHub Pages: push the files to a repository, then Settings > Pages > deploy from the `main` branch, `/ (root)`.
- Netlify: drag the folder onto https://app.netlify.com/drop.

## Notes
- Expected cash = opening float + cash sales - expenses. Difference = counted cash - expected cash.
- Drafts and saved closings are stored in your browser's localStorage and never leave the device.
